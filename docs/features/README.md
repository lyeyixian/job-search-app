# Job search app

The job search app shows the vault in a browser. The person who runs the job search uses it to
see the applications, the market scan, the experience and the plan of the search. In this version
you can read the vault. You cannot change it.

The vault's glossary defines the terms that these files use, such as application, verdict, listing
and triage.

## Features

- [Every page](every-page.md). Use each page in the same way: the menu, no sign-in, the phone, and
  how fresh the data is.
- [Application board](application-board.md). See all the applications, grouped by status.
- [Application page](application-page.md). Read one application: the posting, the fit analysis and
  the tailored resume.
- [Shortlist](shortlist.md). See the open listings that are worth an application, for all
  companies.
- [Company listings](company-listings.md). See all the listings of one company, and read one
  listing.
- [Experience](experience.md). Read the profile, the role notes, the project notes, the stories
  and the skills inventory.
- [Direction and targets](direction-and-targets.md). Read the direction and the targets.
- [Links between notes](links-between-notes.md). Go from one note to a note that it names.

## What applies to every feature

- The acceptance criteria in [Every page](every-page.md) apply to each feature.
